## 🌟 核心功能亮點

### 1. 🎯 20 大常見與特殊攝影場景實戰手冊
每個場景皆包含**推薦光圈、快門速度、ISO、測光對焦策略、推薦鏡頭焦段與必備濾鏡/配件、SOP 步驟以及老手避坑秘笈**：
- **人像與街拍：**
  - 多人團體照 / 全家福（光圈收縮至 f/7.1–f/11、對焦前 1/3 處、防範廣角邊緣人臉拉伸、連拍防閉眼）
  - 85mm 經典半身糖水特寫（極致散景、Eye-AF 眼睛對焦、艷陽天 ND 減光鏡搭配）
  - 35mm / 50mm 旅遊人文隨拍（Zone Focusing 超焦距泛焦 f/8 盲拍、1/250s 安全快門）
  - 135mm / 200mm 戶外長焦人像（空氣切割感、空間壓縮、遠距溝通技巧）
- **風景、流水與晨昏：**
  - 瀑布溪流與絲絹水感（1/4s–2s 絲流美學、CPL 消除岩石反光、ND 減光鏡選型）
  - 晨昏日出日落與藍調時刻（f/11–f/16 刺芒、AEB 包圍曝光、GND 漸變鏡應用）
  - 城市夜景與車流光軌（10s–30s 號誌流線、藍調時段拍攝、關閉防手震）
  - 建築外觀與室內空間（水平儀維持垂直線條防透視畸變、CPL 消除落地窗雜光）
  - 海岸慢門海浪（霧化海面 vs 絲狀浪花、ND1000 慢曝、腳架防海沙陷落）
  - 雪景與高調雪山（「白加黑減」曝光補償 +1.0EV ~ +2.0EV、低溫電池保暖）
- **夜景、星空與特殊天象：**
  - 螢火蟲微光軌跡（大光圈 f/1.4–f/2.0、15s–30s 短曝多張疊圖防熱噪點、紅光手電筒、關閉長曝降噪）
  - 銀河核心與璀璨星空（500 法則 vs NPF 精算法則、ISO 3200–6400、放大手動對焦恆星）
  - 舞動極光（慢速光幕 5-10s vs 跳躍爆發 1-3s 動態快門切換、進室內密封夾鏈袋防潮防霉）
  - 節慶煙火施放（B 門 + 不反光黑卡、f/8–f/11 細緻光柱、上風處站位）
  - 超長焦懸日懸月（等效 400mm–800mm、地景比例透視、大氣熱浪影響）
- **動態、運動與微距：**
  - 運動賽事與飛羽鳥類（1/1600s–1/4000s 極速定格、AF-C 3D 追焦、搖鏡追焦 1/30s）
  - 奔跑寵物與活潑幼童（水平視線平視機位、動物眼部對焦、1/500s+ 快門）
  - 精緻商品商攝與美食靜物（f/8–f/11 全景深、大柔光箱+反光板、景深合成 Focus Stacking）
  - 超微距昆蟲與花卉（1:1 等倍放大、毫米級景深、雙頭微距閃光燈補光、防繞射）
  - 室內舞台與演唱會演講（禁用閃光燈、70-200mm f/2.8、高光重點測光防臉部爆白）

### 2. 🧮 三大光學與曝光實戰計算機

1. **景深 (DoF) 與超焦距 (Hyperfocal Distance) 精密計算機**
   - 支援全片幅、APS-C (Sony/Nikon/Fuji 1.5x、Canon 1.6x)、M4/3、1 吋、中片幅等多種感光元件。
   - 計算前後景深範圍、總景深、超焦距、前後景深比例，並附帶**動態景深條視覺指示**。
   - **實戰情境分析：** 輸入團體站位厚度與距離，系統自動分析目前光圈是否足夠涵蓋全員，並提供最佳對焦位置！
2. **星空銀河不拖尾快門計算機**
   - 同步計算「底片時代 500 法則」、「嚴格 350 法則」以及「現代高畫素 NPF 精算法則」。
   - 根據感光元件尺寸、百萬畫素密度與鏡頭實體焦距，精確給出星點不拖尾的最長安全秒數。
3. **ND 減光鏡曝光換算與長曝計時器**
   - 基準快門測光 ➔ 裝上 ND4 / ND8 / ND16 / ND64 / ND1000 / ND100000 後的精準曝光時間。
   - 內建**現場倒數計時器**，倒數結束自動發出音訊與手機震動提醒！

### 3. 🎒 必備器材與濾鏡選型指南
- CPL 圓形偏光鏡角度與去反光原理
- ND 減光鏡與黑柔焦鏡規格對照
- 腳架使用禁忌（上腳架必關防手震、中軸不升原則）
- 控光與閃光燈跳燈心法
- 光學繞射 (Diffraction) 警戒線（打破「光圈越小越好」的迷思）
